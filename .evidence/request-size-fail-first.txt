THE MEASUREMENT THE FIX IS BUILT ON
Live probe against this project's REST endpoint, 16-Sep-2026, using the anon key: a request
that REACHES PostgREST answers 401 (permission denied for table members); the gateway's own
refusal is a plain 400 Bad Request with no JSON body. Query built by supabase-js itself, the
exact shape fetchCourseDayRows sends.

   629 ids  urlLen 24,643  ->  401   reached PostgREST
   640 ids  urlLen 25,072  ->  401   reached PostgREST
   660 ids  urlLen 25,852  ->  400   refused by the gateway
   700 ids  urlLen 27,412  ->  400   refused by the gateway

The budget is shared with the request HEADERS (binary search on the id count, per header size):
   +0 bytes of extra header   ->  643 ids got through  (urlLen 25,189)
   +700 bytes                 ->  634 ids              (urlLen 24,838)
   +1400 bytes                ->  625 ids              (urlLen 24,487)

The probe carried a 208-byte anon key. The app carries a session JWT plus everything a browser
adds, which is comfortably more than +1400 - so the app's own cliff is at or below 625 ids.
Postnatal's roster on Tue 15 Sep 2026 is 629 members (629 attendance_records on that day for
that course, counted in production before the fix).
