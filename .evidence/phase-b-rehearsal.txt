4. WHAT THE HARNESS CANNOT PROVE, AND WHAT WAS DONE INSTEAD
   CLAUDE.md is explicit: the harness holds no data, so it proves a migration
   is well-formed BY RECONSTRUCTION and cannot prove it is compatible with the
   rows production already has. 0067 creates no index and adds no constraint,
   so nothing is validated over existing rows -- but the BEHAVIOUR still had to
   be checked against real data, and was, read-only, before any apply: the
   function's body was run as a plain SELECT against production. See
   .evidence/0067-production-preview.txt.
